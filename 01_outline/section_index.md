# 4장. 숨은이름 시장

## 별조각 주제

**착한 척** — 주인공 인정 말: "나도 그런 적 있어. 말 안 해도 되면, 안 했어. 싫은데도 괜찮다고 했어. 내가 참으면 조용해질 거라고 생각했어. 근데 그게 쌓이면 나중엔 뭘 말하고 싶은지도 모르게 돼."

# 6장. 열리지 않는 문

## 목표

세 별조각으로 현실의 문을 여는 순간, 귀환문 담당자인 **문지기**가 나타나고 이안이 함께 돌아갈 수 없다는 사실이 드러난다.
이안의 진실은 이안이 긴 고백으로 설명하는 것이 아니라, 문지기의 귀환 심사 과정에서 수동적으로 폭로된다.
폭로(6장)와 고백(7장)의 차이가 두 챕터를 가른다.

## 폭로의 세 겹

1. **1층**: "이안"은 진짜 이름이 아니다 — 동행자가 찢어진 문장 "이 안에 있어"에서 따준 빌린 이름
2. **2층**: 이안의 동기에는 자기 목적이 섞여 있었다 — 주인공의 별조각이 모여야 녹슨 열쇠도 반응한다는 사실을 알고 있었다
3. **3층**: 동행자를 잃은 건 이안 탓만은 아니지만, 말해야 할 순간에 또 침묵해서 길이 어긋났다

독자는 이안에게 배신감을 느낄 수 있지만 동시에 이안의 공포를 이해하기 시작한다. 단, 과거의 전말과 이안의 진심은 7장에서 이안이 자기 입으로 말해야 한다.

## 섹션 목록 (집필 완료)

- S064. 다시 나타난 현실의 문 — 세 별조각으로 귀환문이 열리고 문지기 등장
- S065. 문지기의 심사 — 주인공 귀환 자격 확인, 이안의 이름 문제 노출
- S066. 말하지 않은 열쇠 — 녹슨 열쇠가 주인공 별조각에 반응한다는 사실 폭로
- S067. 이번에도 말하지 않은 아이 — 이안의 오래된 침묵과 이전 동행자 암시
- S068. 열린 방과 남겨진 문턱 — 최종 2선택: 방으로 들어가거나, 돌아가지 않거나
- E001. 혼자 돌아온 방 — 방으로 들어간 선택의 엔딩
- S070. 어스름의 심장으로 — 돌아가지 않는 선택의 7장 진입

## 게임 요소

- 선택지는 딱 2개만 둔다: **방으로 들어간다(E001)** / **돌아가지 않는다(S070)**
- E001은 처벌성 배드엔딩이 아니라 정당하지만 미해결의 여운이 남는 귀환 엔딩이다.

# 7장. 어스름의 심장

## 목표

사잇별의 땅 중심에서 이안의 기억 조각을 모으고, 이안이 삼켜온 진심을 직접 말하는 순간을 만들어 이름을 되찾는다.
이안의 이름 회복은 외부에서 이름을 "조합해서 돌려주는" 것이 아니라, **이안이 자기 목소리를 내는 행위 자체**로 이루어진다.

## 7장 설계 핵심 원칙

**기억 조각 = 이안이 말하지 못하고 삼킨 순간들**
- 각 조각은 어스름의 심장 안에 "얼어붙은 장면"으로 존재
- 주인공이 "이안이 이 순간 무엇을 삼켰는지"를 정확히 알아봐야 조각이 풀림
- 이안은 자기 기억을 직접 볼 수 없어 등을 돌린 채 따라옴 → **역할 역전**: 주인공이 이안의 세계를 대신 걷는다

**이름 퍼즐(P007) 재설계**
- 조각을 다 모아도 마지막 한 칸이 비어 있음
- 빈 자리는 이안 자신이 채워야 함 — 주인공: "네가 채워야 하는 것 같아."

**이안의 고백이 이름 회복의 조건**
- "말하면 네가 날 싫어할 수도 있어. 그래도 말할게."
- 이안의 목소리가 열리는 순간 이름이 돌아오고 녹슨 열쇠가 반응

## 섹션 초안

- S070. 어스름의 심장으로 — 6장에서 “돌아가지 않는다”를 선택한 뒤 진입
- S071. 어스름의 심장 — 잊힌 말들이 별이 되는 곳, 기억 조각 규칙 제시
- S071A. 기억 조각 ① — 동행자와의 초반 (이안이 말하려다 삼킨 순간) ← **삽화 S071A 필요**
- S071B. 기억 조각 ② — 말해야 했던 순간 (이안의 진짜 동기 — "내가 짐이 될까 봐") ← **삽화 S071B 필요**
- S071C. 기억 조각 ③ — 마지막 문 앞에서 (이안이 막으려 함 + 주인공의 선택) ← **삽화 S071C 필요**
- S072. 빈 조각이 있는 이름 퍼즐 / 이안의 고백 (이안이 직접 말하는 순간 → 이름 회복)
- S073. 녹슨 열쇠가 반응하다
- S074. 마지막 선택 — 이안: "같이 갈 수 있어?" / A.이안 손을 잡는다→E002 / B.발이 멈춘다→S075 / C.너 먼저 가→E004
- S075. 별빛 균열 — 주인공이 자신의 별빛을 처음으로 말함 → E003 (진엔딩)

## 게임 요소 후보

- P007. 이름 퍼즐 — 마지막 빈 칸은 이안이 채움 (주인공이 조합하는 구조 아님)
- P008. 기억 조각 수집 — 각 조각마다 "이안이 삼킨 것이 무엇인가" 선택으로 풀기
  - 조각 ①: 난이도 낮음. 이안도 자기 얘기를 하고 싶었다.
  - 조각 ②: 난이도 중간. "말하면 내가 짐이 될까 봐 두려웠다" — 이안 자신도 자각 못한 동기.
  - 조각 ③: 난이도 없음. 주인공이 이안의 저항을 넘고 끝까지 보기만 하면 됨.
- BE008. 이안의 이름을 잘못 부르다 — 주인공이 단서를 조합해 이름을 "대신 불러주려" 할 때 발동. 이름은 외부에서 주는 것이 아니라 이안이 스스로 말해야 한다.

## 주인공-이안 대칭 구조

| | 주인공 | 이안 |
|---|---|---|
| 잃은 것 | 별조각 (삼켜온 진심들) | 이름 (삼켜온 목소리) |
| 회복 조건 | 두려운 감정을 말로 인정함 | 두려운 진심을 상대에게 말함 |
| 조력자 | 이안 (공간을 열어줌) | 주인공 (빈 조각을 내밀어줌) |
| 핵심 공포 | 인정받지 못하면 사랑받지 못한다 | 말하면 상대가 떠난다 |
| 회복의 역설 | 인정해야 앞으로 갈 수 있다 | 말해야 이름이 돌아온다 |
