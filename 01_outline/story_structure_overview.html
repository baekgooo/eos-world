챕터별 스토리 + 퍼즐/함정

Prologue

내 방에 없던 문 S001~S010

완성

핵심: 현실이 어긋나고, 이안이 나타나며, 주인공이 사잇별의 땅으로 넘어간다.

  • 시계가 멈추고, 창밖이 이상해지고, 휴대폰에 알 수 없는 문장이 뜬다.
  • 방 안에 없던 문이 생기고, 문틈에서 이안 등장.
  • 첫 선택: 이안을 믿을지 / 문밖을 직접 볼지 / 작은 글씨를 다시 볼지 / 방에 남을지
  • 방에 남는 선택 → 방이 접히는 위협 → 결국 본편 합류 (완전 배드엔딩 아님)
"이안이라고 불러." / "그게 네 이름이야?" / "지금은."

퍼즐/함정: 없음. 도입부 — 선택·관찰 중심.

Chapter 1

사잇별의 땅 S011~S019

완성

핵심: 돌아가는 문이 사라진 걸 확인하고, 이 세계의 첫 규칙을 체험한다.

이안은 길을 아는 사람이 아니라 길을 잃어본 사람 — 정답을 대신 알려주지 않는다.

P001세 갈래 표지판

표지판문구결과
왼쪽 "돌아가고 싶은 자는 왼쪽으로." 길이 원점으로 돌아옴 → 재도전
오른쪽 "잃어버린 것을 찾는 자는 오른쪽으로." 가짜 물건들, 그림자가 발목을 잡음 → 재도전
가운데 낡은 돌 (작은 글씨) "정말로 원하는 길은 크게 쓰이지 않는다." —
정답 C 표지판 뒤쪽의 숨은 좁은 길을 살핀다 초저녁 정거장으로 진행
D 이안에게 전부 맡긴다 이안: "여기서는 네가 봐야 해." → 재도전
핵심 규칙: 크게 쓰인 말보다 작고 희미한 단서가 진실에 가깝다. — 이후 모든 퍼즐의 원칙.

첫 퍼즐이므로 오답은 회복 가능. 죽이지 않고 단서를 다시 배우게 함.

Chapter 2

초저녁 정거장 S020~S030

완성

핵심: 첫 공공장소 탐험. 친절한 역무원 함정을 겪고, 세 별조각이라는 전체 목표를 손에 넣는다.

  • 선로 없는 승강장, 말하는 시간표, 너무 친절한 역무원.
  • 표지판 수선공 등장 — 큰 글씨/작은 글씨 세계 규칙 설명. 이안이 모든 설명을 맡지 않게 함.
  • 이안도 주인공을 어딘가로 움직이게 한다는 독자의 의심 시작.

T001친절한 역무원 사기꾼 함정

너무 안전하고 너무 친절한 역무원 → 믿으면 이름을 빼앗김 (BE001)
단서: 역무원의 이름표에 이름이 없거나 작은 글씨로 경고가 있음.

P002시간표 해독

말하는 시간표의 큰 글씨와 작은 문장을 대조해 진짜 출발 정보를 읽음.
정답 루트 → 거울숲 가는 표 + 세 별조각 목표 획득.

실패 페이지: BE001 역무원에게 이름을 빼앗기다 / BE002 표지판의 유혹 길에 갇히다

Chapter 3

거울숲 S031~S039

완성

핵심: 주인공이 숨기고 싶은 마음과 마주하고, 첫 번째 별조각을 얻는다. 이안의 비밀 암시 시작.

별조각 주제 ①: 부족함 — "잘하지 못할까 봐 무서웠어. 실망시키면 사랑받지 못할까 봐 무서웠어."

거울들이 얼굴이 아니라 숨기고 싶은 마음을 비춤. 이안 뒤에 숨으면 거울이 이안의 빈 이름을 비추며 이안이 흔들림.

P003진짜 거울 찾기

선택거울결과
A 웃는 거울 — "걱정하지 않아도 되는 길" 발밑 그림자 사라짐. 도망이 만든 얼굴. → 재도전
B 빈 거울 — "아무것도 보지 않아도 되는 길" (깨기) 조각마다 보지 않으려던 표정이 더 날카롭게. → 재도전
C (정답) 보기 싫은 거울 — 작은 글씨: "그래도 봐야 지나간다" 거울 뒤 길이 열림 → S037 진행
D 이안 뒤에 숨기 이안의 빈 이름이 비쳐 이안이 흔들림 → 재도전
  • S037: 이안의 그림자가 본체보다 한 박자 늦게 따라옴 — 이안 의심 강화
  • S038: 첫 번째 별조각 획득 (젖은 유리 조각에 별빛이 갇힌 느낌)
  • S039: 마지막 거울 속 목소리 — "그 애를 끝까지 믿지 마" (완전한 거짓말이 아님)
Chapter 4

숨은이름 시장 S040~S053 + 분기 섹션

완성

핵심: 이름·기억을 사고파는 블랙마켓에서 두 번째 별조각을 찾고, 이안의 이름 조각이 시장에 흘러다니고 있다는 사실이 드러난다.

별조각 주제 ②: 착한 척 — "나도 그런 적 있어. 말 안 해도 되면 안 했어. 싫은데도 괜찮다고 했어. 내가 참으면 조용해질 거라고 생각했어. 근데 그게 쌓이면 나중엔 뭘 말하고 싶은지도 모르게 돼."

시장 세계관: 불편한 감정·기억·이름을 팔면 편안함을 준다. 상인들은 거짓말을 하지 않는다. 약속한 것을 정확히 준다. 다만 뭘 잃는지 먼저 말하지 않는다. 팔수록 가벼워지지만 흐려진다.

P005별조각 거래 연쇄 추적 (S044)

시장 거래 기록판 + S040~S041 관찰 단서 조합 → 별빛 조각의 현재 보유자를 논리 추론.
단서: 동쪽 끝 말없는 여자(S040 관찰) + 빨간 스카프·잿빛 손 거래(S041 관찰) + 기록판(S044). 잿빛 손 상인 새벽 출발 + 담보 기한 미경과 → 말없는 여자 보관 중.

P004거짓말쟁이 상인 찾기 (S045) — 소거형 분기

선택상인결과
A (정답) 조용한 여자 — 몸짓으로만 거래 S051 클라이맥스 진행
B 웃는 가면 상인 — 먼저 다가와 조건 설명 제안 S046A → 이름 요구 함정 → S047A(여자+아이) 또는 S049(이름BE)
C 불쌍한 아이 — "따라오면 데려다줄게요" (T002) S046B → 골목 함정 → S047B(여자+상인)

소거형 분기: 함정을 거칠수록 선택지가 줄어듦 → S047A/B(2명) → S048A/B(함정 2차) → S050(여자만) → S051

테마 연결: 착한 척하는 것이 가장 위험하다. 먼저 친절하게 말 거는 쪽이 가짜. 이 챕터의 핵심 주제가 퍼즐로 구현됨.

함정 S046A — 거짓말쟁이의 덫 (이름 요구)

상인이 봉인된 상자를 보여주며 "확인용으로 이름만 말해달라"고 함.
이름을 말하면 → S049(이름 빼앗기다). 말하지 않으면 → S047A(여자+아이 소거 씬).
이안의 경고 "이름을 함부로 말하지 마"가 여기서 의미를 가진다. 함정은 한 턴 뒤에 발동.

감정 클라이맥스 S051 — 팔면 안 되는 것

말없는 여자가 주인공에게 쪽지: "싫다는 마음을 맡기면 편해집니다."
이안에게 쪽지: "당신이 하지 못한 말들을 보관해드립니다. 다시는 말할 필요 없어요."
이안이 쪽지에 손을 뻗으려 한다. 주인공이 "이안 일이야"라며 침묵하려는 충동을 알아차리고 개입: "이안, 하지 마."
이안이 "네가 뭘 알아"라고 반발. 주인공이 물러서려는 충동을 다시 인식하고 말한다:
"나도 그런 적 있어. 말 안 해도 되면 안 했어. 싫은데도 괜찮다고 했어."
이안이 거래 중단. 바닥에서 별빛 응고 → S052에서 말없는 여자가 건네줌.

이안 아크 요약

  • S043: 이름 수집가 아이 — "당신 이름 조각 갖고 있어요. 한동안 됐는데 찾으러 안 오셨길래." 이안 충격.
  • S051: "말하지 않아도 되는" 거래 유혹에 흔들림 → 주인공 개입으로 거래 중단.
  • S053: "그게 진짜 네 이름이야?" / "지금은." — 이름 조각을 받지 않고 걷기 시작.

실패 페이지: S049 이름을 빼앗기다 / S046B·S048A 가짜 안내자 함정

Chapter 5

밤끝탑 S054~S063 + S057A/B

기획 완료

핵심: 이안이 탑 입구에 남고, 주인공이 혼자 탑 안으로 들어가 두려움과 마주한다. 세 번째 별조각.

별조각 주제 ③: 실패와 선택 — "나는 틀릴까 봐 무서워. 하지만 틀리지 않으려고 내 선택을 버리지는 않을 거야."

섹션 흐름

S054 검은 탑 앞에서 (이안이 탑의 정체 설명) → S055 이안이 남는다 (빛 단서 · 6장 복선) → S056 올라갈수록 내려가는 곳 (단서 심기) → S057 세 개의 목소리 [P006]
A → S057A 또 다른 나(부정의 방) → S058
B → S057B 또 다른 나(도피의 방) → S058
C → S058 직행
→ S058 두려움의 심장 → S059 세 번째 별조각 → S060 탑을 나서다 (이안 재회) → S061 녹슨 열쇠가 반응하다 (6·7장 복선) → S062 세계 가장자리가 흐릿해지다 → S063 챕터5 마감

이안 분리 씬 (S055) — 6장 복선

탑 입구 빛이 주인공의 윤곽을 밝히지만, 이안에게 닿으면 스며들어 윤곽이 흐릿해진다. 주인공이 이것을 목격하지만 말하지 않는다.
이안: "이건 혼자 가야 해." 이유는 말하지 않는다. "나올 때 내가 여기 있을게." — 이유가 아니라 약속.
→ 6장에서 이안이 귀환의 문 앞에서 멈출 때 이 단서가 회수된다.

P006세 개의 목소리 — 감정 선택 퍼즐

사전 단서: S056에서 두 가지 중립적 흔적(벽의 선언 "아무것도 무섭지 않다" + 돌아간 발자국). 정답을 지시하지 않음.

목소리선택의 의미심리 구조결과
A 두려움을 느끼지 않기로 하고 문을 연다 감정 외면 / 부정 S057A → 또 다른 나(감각이 꺼진 얼굴)를 만남 → 진심 인정 후 S058
B 무서우니까 멈추는 게 맞다고 결론 짓고 선택을 포기한다 자기합리화 / 도피 S057B → 또 다른 나(표류 중인 나)를 만남 → 진심 인정 후 S058
C (정답) 무서운 채로, 틀릴 수 있어도, 내가 선택하고 문을 연다 감정 인정 + 선택 책임 S058 직행
P006 설계 원칙: 세 선택지 모두 배드엔딩 없음. A/B는 자아 대면 씬(S057A/B)을 거쳐 S058로 수렴. C는 직행. 정답을 고른 독자는 짧고 깊은 경험, 오답 독자는 더 긴 자기 탐색.
B의 자기합리화: B는 A처럼 명령하지 않고 계속 이유를 갖다붙이며 납득시키려 든다. "~하는 게 맞아", "~도 선택이야" — 이유가 많을수록 스스로 확신 없다는 신호. 독자가 B 뒤에 어딘가 불편함을 느끼도록 집필.

또 다른 나 씬 (S057A / S057B)

  • S057A (부정의 방): 표정 없는 나 — "두려움을 느끼는 기능을 잃어버린 나". 대화 끝에 주인공이 "응, 무서워"를 처음 인정하면 균열이 열린다.
  • S057B (도피의 방): 벽에 기대앉은 나 — "돌아가다가 돌아갈 곳이 없어서." 멈춤이 안전이 아니라 표류가 됐다. 대화 끝에 주인공이 "응, 가고 싶어"를 처음 인정하면 문이 열린다.
S057A/B의 구조는 7장 이안의 고백씬과 구조적 메아리다. 이안도 같은 방식으로 진심을 인정해야 이름이 돌아온다.

세계 가장자리 징조 (S062) — 7장 복선

사잇별의 땅이 무너지는 게 아니라, 귀환의 창(현실로 돌아가는 통로)이 닫히는 징조다. 이안은 이 징조를 오래전부터 알고 있었으면서 말하지 않았다. "빨리 가야 해"는 이제야 내뱉는 말.
→ 6장에서 이 침묵도 이안의 패턴 폭로 재료가 된다.

Chapter 6

열리지 않는 문 S064~S068 + E001 + S070

완성

핵심: 세 별조각으로 현실의 문을 여는 순간, 이안이 함께 돌아갈 수 없다는 사실이 드러난다.

이안의 진실은 이안이 긴 고백으로 설명하는 것이 아니라 문지기의 귀환 심사 과정에서 수동적으로 폭로된다. — 폭로(6장)와 고백(7장)의 차이가 두 챕터를 가른다.

폭로의 세 겹 (수동적)

층위드러나는 진실
1층 "이안"은 진짜 이름이 아니다 — 동행자가 찢어진 문장 "이 안에 있어"에서 따준 빌린 이름
2층 이안의 동기에는 자기 목적이 섞여 있었다 — 주인공의 별조각이 모여야 녹슨 열쇠도 반응한다는 사실을 알고 있었다
3층 동행자를 잃은 건 이안 탓만은 아니지만, 말해야 할 순간에 또 침묵해서 길이 어긋났다
문지기는 성스럽고 친절한 안내자가 아니라, 귀환문 담당 공무원처럼 까칠하고 빈정거리는 존재다. 그래서 폭로가 설명충처럼 느껴지지 않고 “심사 중 드러난 사실”로 작동한다.

핵심 선택 분기

  • 방으로 들어간다 → E001. 혼자 돌아온 방
  • 돌아가지 않는다 → S070. 어스름의 심장으로
Chapter 7

어스름의 심장 S070 진입 완료 / S071~S073 예정

미작성

핵심: 사잇별의 땅 중심에서 이안의 기억 조각을 모으고, 이안이 삼켜온 진심을 직접 말하는 순간으로 이름을 되찾는다.

이안의 이름 회복은 퍼즐로 "조합"되는 것이 아니라, 이안 자신이 목소리를 내는 행위로 이루어진다.

P008기억 조각 수집 — 삼킨 순간 알아보기

기억 조각 = 이안이 말하지 못하고 삼킨 순간들. 어스름의 심장에 얼어붙은 장면으로 존재.
이안은 자기 기억을 직접 볼 수 없어 등을 돌린 채 따라옴 — 주인공이 대신 목격. 역할 역전.

조각장면알아봐야 하는 것삽화
① 동행자와의 초반 이안이 말하려다 삼킴. 동행자는 앞을 본다. 이안도 자기 얘기를 하고 싶었다 S071A 예정
② 말해야 했던 순간 동행자가 잘못된 방향으로. 이안의 몸이 반응하다 굳음. 말하면 내가 짐이 될까 봐 두려웠다 S071B 예정
③ 마지막 문 앞 이안이 막으려 함 → 주인공 선택 → 동행자 사라짐 끝까지 보기만 하면 됨 (선택지 없음) S071C 예정
⚠ 조각 ③ 앞에서 이안이 처음으로 "이건 안 봐도 돼"라고 막음. 주인공이 멈추면 → 퍼즐 미완성으로 막힘.

P007이름 퍼즐 — 빈 마지막 조각

기억 조각을 다 모으면 이름 퍼즐이 열리지만 마지막 한 칸이 비어 있다.
주인공이 아무리 맞춰도 채워지지 않음 — 이 자리는 이안이 채워야 한다.
주인공이 이안에게 빈 조각을 내밀며: "네가 채워야 하는 것 같아."

이안의 고백 → 이름 회복

이안은 주인공이 자기의 가장 부끄러운 장면까지 봤다는 걸 안다. 판결을 기다린다.
주인공이 떠나지 않고 빈 조각을 내밀었을 때, 이안이 말한다:

"말하면 네가 날 싫어할 수도 있어. 그래도 말할게."

이 문장이 이름을 되돌린다. 녹슨 열쇠가 반응 — 동행자와의 약속이 비로소 이행됨.

배드엔딩 BE008 — 이름을 잘못 부르다

주인공이 단서를 조합해 이안의 이름을 "대신 불러주려" 할 때 발동.
이름은 외부에서 주는 것이 아니라 이안이 스스로 말해야 한다. 이 실패는 이안이 이름을 잃게 된 원인의 반복 — 누군가가 이안을 정의해주는 것.

기타 실패 페이지: BE009 잘못된 별을 고르다 / BE010 문이 닫힌 뒤 혼자가 되다

주인공-이안 대칭 구조

이안의 비밀 — 서사 스레드

프롤로그

5장

6장

문지기의 귀환 심사 중 이안이 함께 돌아갈 수 없는 이유가 수동적으로 폭로됨.
"이안"이 빌린 이름이었다 / 녹슨 열쇠가 별조각에 반응한다는 사실을 숨겼다 / 침묵으로 동행자를 놓쳤다 — 세 겹으로.

7장 (이안의 고백)

주인공이 이안의 기억 조각(삼킨 순간들)을 목격한 뒤, 빈 퍼즐 조각을 내밀며: "네가 채워야 하는 것 같아."
이안이 처음으로 스스로 말하기로 선택한다:
"말하면 네가 날 싫어할 수도 있어. 그래도 말할게."
이 문장이 이름을 되돌린다. 녹슨 열쇠 반응 — 동행자와의 약속 이행.
