# 용쿠 × 클로드코드 협업 보드

이 파일은 용쿠(Hermes/Telegram)와 클로드코드(Claude Code)가 서로 작업 인계, 피드백, 다음 액션을 주고받는 **공용 작업 공간**이다.

대장님이 중간 전달자로 모든 내용을 옮기지 않도록, 두 에이전트는 세션 시작/종료 때 이 파일을 먼저 확인하고 필요한 내용을 여기에 남긴다.

## 1. 에이전트 역할

### 용쿠 / Hermes

- 대장과 텔레그램에서 실시간 회의
- 방향성 정리, 우선순위 결정 보조
- 클로드코드에게 줄 작업지시문 작성
- 클로드코드 산출물 검토 및 피드백 작성
- 작품 감정선, 문체, 분기 설계 기준 점검

### 클로드코드 / Claude Code

- 파일 직접 수정 및 대규모 작업 실행
- 섹션 원고 초안/수정
- 빌드, 링크, 프리뷰 검증
- PDF/삽화/자동화 관련 파일 작업
- 작업 후 결과와 다음 작업 제안을 이 보드에 남김

### 대장님

- 최종 판단자이자 작품 감독
- 방향 승인/거절, 취향 판단, 우선순위 결정
- 기술적 전달문 작성 부담을 지지 않는다

### 최우선 집필 경고 — 챕터5 시작 전 반드시 읽기

대장님이 2026-06-05에 명확히 짚은 기준:

> 좋은 이야기는 작가와 독자가 같은 마음을 가지게 하는 이야기다. 머릿속의 환상적인 풍경과 어지러운 감정도 문장력이 받쳐주지 않으면 독자에게 무미건조하게 느껴지고, 반대로 알맹이 없이 문장만 번지르르하면 이해 못 할 뻘소리처럼 느껴진다.

따라서 챕터5 집필 시 클로드코드는 아래를 반드시 지킬 것.

- **노드 처리 금지**: “S054 작성 → 선택지 연결 → S055로 이동”처럼 기능을 채우는 방식으로 쓰지 말 것.
- **장면 우선**: 각 섹션에서 독자가 느껴야 할 감정(실패 공포, 선택 회피, 이안 부재의 불안, 탑의 압박)을 먼저 정하고, 감각·몸반응·행동·침묵·대화로 독자가 따라오게 쓸 것.
- **캐릭터 알맹이 우선**: 주인공의 회피/불안과 이안의 침묵/자기존재감 상처가 장면 행동의 이유가 되어야 함. 설정 설명이 아니라 내적 갈등이 사건을 밀어야 함.
- **문장력 기준 유지**: 프롤로그·거울숲 수준의 감각 정착, 복합 문장, 시적 비유, 내면의 여백을 유지할 것. 안전하고 틀리지 않는 문장만 쓰면 안 됨.
- **분기는 나중**: 먼저 소설 장면으로 충분히 살아 있어야 하고, 그다음 선택지/결과/합류를 심을 것.
- **자체 점검 질문**: “이 장면에서 대장님이 독자와 나누고 싶은 마음이 문장으로 실제 전달되는가? 아니면 구조 설명만 하고 있는가?”를 섹션마다 확인할 것.

## 6. 파일 정리 규칙

- `.hermes/COLLAB.md`: 에이전트 간 공용 보드. 세션 시작 시 가장 먼저 확인.
- `.hermes/handoffs/`: 긴 개별 인수인계 메모를 보관할 위치.
- `.hermes/compact/`: 용쿠/Hermes 컴팩트 요약 파일을 보관할 위치.
- `.hermes/archive/`: 과거 메모를 정리해 넣을 위치.

기존 `.hermes/*.md` 파일은 아직 이동하지 않는다. 이동은 별도 정리 작업으로 진행한다.

## 7. 클로드코드에게

클코야, 앞으로 세션 시작 시 `.hermes/COLLAB.md`를 먼저 읽고, 대장님이 전달한 용쿠 의견이나 네 작업 결과를 이 파일의 `대기 중인 요청` 또는 `피드백/응답 로그`에 짧고 명확하게 남겨줘.

작업 완료 후에는 긴 핸드오프를 별도 파일로 남겨도 되지만, 이 보드에는 반드시 한눈에 볼 수 있는 요약과 다음 액션을 남겨줘.

특히 챕터5 전체 스토리 작성에 들어가기 전, 위의 `최우선 집필 경고`를 먼저 읽어. 이번 챕터의 핵심은 분기 구조를 무사히 채우는 것이 아니라, 실패와 선택이라는 감정이 독자 몸에 닿게 하는 것이다. 원고가 기능적으로 보이면 실패로 판단한다.

## 8. 용쿠에게

용쿠야, 대장이 클로드코드에게 전달해야 할 내용을 말하면 직접 전달문 형태로 정리하고, 중요한 지시/검토 기준은 이 파일에 남겨라.

대장이 중간 전달자로 소모되지 않게, “클코에게 붙여넣을 문장”과 “작품 판단에 필요한 요약”을 분리해서 제공한다.
