# .hermes 폴더 정리 규칙

이 폴더는 용쿠(Hermes)와 클로드코드(Claude Code)의 프로젝트 협업 메모 공간이다.

## 핵심 파일

- `COLLAB.md`: 공용 협업 보드. 세션 시작 시 가장 먼저 읽는다.

## 권장 하위 폴더

- `handoffs/`: 긴 개별 인수인계 메모
- `compact/`: Hermes/용쿠 컴팩트 요약
- `archive/`: 과거 메모 보관

## 운영 원칙

1. 대장님이 모든 내용을 손으로 중계하지 않도록, 에이전트가 직접 읽을 수 있는 형태로 남긴다.
2. 새로운 작업 요청이나 피드백은 우선 `COLLAB.md`에 짧게 남긴다.
3. 긴 세션 기록은 별도 파일로 보관하되, `COLLAB.md`에는 반드시 요약과 다음 액션을 남긴다.
4. 기존 루트의 과거 메모 파일은 당장 이동하지 않는다. 정리 작업이 필요할 때 별도 커밋으로 이동한다.
