```
S045(3명) → 상인 → S046A → 이름거부 → S047A(여자+아이)
S045(3명) → 아이  → S046B → S047B(여자+상인)
S047A     → 아이  → S048A → S050(여자만)
S047B     → 상인  → S048B → 이름거부 → S050
S049(이름BE) → S050
S050      → S051(정답)
```
